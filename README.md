## 📌 Executive Summary
This capstone project delivers an end-to-end exploratory and diagnostic data analysis of global bike sales performance. The primary objective is to clean, transform, and model raw transaction records to uncover key demographic drivers, purchasing trends, and revenue patterns using **Microsoft Excel**.

By standardizing demographic variables and analyzing commute patterns, income levels, and regional demand, this dashboard translates raw transactional data into actionable commercial insights for sales and marketing optimization.

## 🎯 Key Objectives
* **Data Cleansing & Transformation:** Deduplicate, standardize missing values, and normalize categorical parameters (e.g., Marital Status, Gender, Age Brackets).
* **Exploratory Data Analysis (EDA):** Identify primary revenue drivers across income brackets, commute distances, and regional demographics.
* **Interactive Business Intelligence:** Build a dynamic Excel dashboard leveraging Pivot Tables, Slicers, and custom KPIs to support executive decision-making.

## 🛠️ Data Pipeline & Methodology
1. **Data Cleaning & Quality Assurance:**
   * Handled duplicate entries and null attributes.
   * Standardized encoded binary values (e.g., `M/S` to `Married/Single`, `F/M` to `Female/Male`).
   * Created custom age grouping logic via conditional logic (`Nested IF` / `IFS`).
2. **Data Modeling & Aggregation:**
   * Structured transactional data into normalized Pivot Tables to isolate core sales drivers.
   * Calculated key metrics including Average Income per Purchase, Commute-to-Purchase Ratio, and Regional Unit Volume.
3. **Dashboard Design & Visualization:**
   * Implemented interactive timeline slicers and cross-filtering controls.
   * Visualized sales distribution across customer age brackets, region, and commute length.

## 📊 Key Business Insights
* **Income vs. Purchase Velocity:** Higher-income brackets exhibit a significantly higher conversion rate for mountain and road bike segments.
* **Commute Distance Factor:** Customers commuting **0–1 miles** represent the highest purchase volume, indicating strong utility-driven buying behavior.
* **Regional Performance:** North America led in overall volume, while Europe showed higher average spend per customer unit.
